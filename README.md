# C Programming Collection: Basic to Advance 🚀

Welcome to the ultimate collection of C programming source codes! This repository covers everything from the absolute fundamentals of the C language to highly advanced concepts.

## 📂 Repository Structure

The codes are organized logically so you can find exactly what you need:

### 🟢 1. Basics (Beginner)
* Variable declarations, data types, and operators
* Input/Output formatting (`printf`, `scanf`)
* Conditional statements (`if-else`, `switch-case`)
* Loops (`for`, `while`, `do-while`)

### 🟡 2. Intermediate
* Arrays (1D and 2D matrices)
* Strings and string manipulation functions
* Functions (Call by value & Call by reference)
* Pointers and memory addresses

### 🔴 3. Advanced
* Structures and Unions
* Dynamic Memory Allocation (`malloc`, `calloc`, `realloc`, `free`)
* File Handling (Reading and writing to files)
* Preprocessor directives and macros

---

## 🛠️ How to Use This Code

All programs in this repository are written as **independent, standalone code files**. You do not need to download or clone the whole project to run a single file.

1. **Browse** through the folders and open the program you want to try.
2. Click the **Copy** icon in the top-right corner of the code window on GitHub.
3. Paste the code straight into **any IDE or compiler that supports C** (such as VS Code, Dev-C++, Code::Blocks, CLion, or online compilers like OnlineGDB).
4. Save the file with a `.c` extension, compile, and run!
